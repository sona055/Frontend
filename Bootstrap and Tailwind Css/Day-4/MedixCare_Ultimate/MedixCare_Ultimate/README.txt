MEDIXCARE ULTIMATE

This is an advanced front-end medicine/healthcare website concept.

UPGRADES:
- Real healthcare photography with consistent object-fit cropping
- Responsive mobile/tablet/desktop design
- Safety-first information architecture
- Step-by-step instructions for medicine, prescriptions, appointments and urgent situations
- Medication safety section based on WHO/FDA educational guidance
- Medicine explorer with filters, search, detail modals and demo cart
- Persistent cart using localStorage
- Doctor directory + appointment UI
- BMI tool
- Medicine reminder
- First-aid guide
- Emergency guidance
- Health Hub
- FAQ
- Dark mode
- Scroll reveal animations
- Hover/image zoom transitions
- Scroll progress indicator
- Reduced-motion accessibility support
- Mobile navigation
- Keyboard Escape for dialogs

IMPORTANT:
This is a demo website, not a real pharmacy, medical service or diagnostic tool.
Catalogue products, prices, doctors and transactions are demo content.
Real photos are loaded remotely, so internet is needed for the images and font.

RUN:
Extract ZIP -> open folder in VS Code -> open index.html with Live Server.
