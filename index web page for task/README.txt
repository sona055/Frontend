FRONTEND HUB - EDITABLE VERSION

Open this folder in VS Code.

Structure:
technology -> day -> task -> actual editable source files

Example:
css/day1/task1/index.html
css/day1/task1/style.css

JavaScript example:
javascript/day1/task1/index.html
javascript/day1/task1/style.css
javascript/day1/task1/script.js

To edit:
1. Extract the ZIP.
2. Open the extracted FrontendHub_Reorganized folder in VS Code.
3. Open the task folder.
4. Edit index.html, style.css, and script.js (for JavaScript tasks).
5. Save the file.
6. Open the task index.html in a browser to see the result.

Important:
- Do NOT edit the ZIP file itself.
- Edit the extracted folder.
- The existing task pages in the uploaded ZIP were placeholder/sample pages, so this reorganized version preserves them and makes their source files editable.
- You can replace the sample code with your real daily task code.
